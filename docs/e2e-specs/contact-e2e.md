## 各テスト項目の詳細

### E2E-CONTACT-001: ページ表示確認

**操作手順**:
1. `/contact-support` にアクセス
2. ページタイトル「問合せサポート」を確認
3. FAQセクションが表示されることを確認
4. お問い合わせフォームが表示されることを確認
5. システム情報カードが表示されることを確認

**期待結果**:
- タイトル「問合せサポート」が表示される
- FAQセクションに複数のFAQ項目が表示される
- お問い合わせフォームに「問合せ種別」「件名」「内容」「連絡先メール」が表示される
- システム情報に「バージョン」「最終更新」「稼働状況」が表示される

---

### E2E-CONTACT-002: FAQ展開・閉じる操作

**操作手順**:
1. `/contact-support` にアクセス
2. 最初のFAQ項目をクリック（展開）
3. 回答が表示されることを確認
4. 同じFAQ項目を再度クリック（閉じる）
5. 回答が非表示になることを確認

**期待結果**:
- クリックでFAQが展開し、回答テキストが表示される
- 再クリックでFAQが閉じ、回答が非表示になる

---

### E2E-CONTACT-003: 複数FAQの展開動作確認

**操作手順**:
1. `/contact-support` にアクセス
2. FAQ項目1をクリック（展開）
3. FAQ項目2をクリック（展開）
4. FAQ項目1が自動で閉じることを確認
5. FAQ項目2のみが展開状態であることを確認

**期待結果**:
- 新しいFAQを開くと、前に開いていたFAQが自動で閉じる（アコーディオン動作）
- 常に1つのFAQのみが展開状態

---

### E2E-CONTACT-004: お問い合わせフォーム入力フロー

**操作手順**:
1. `/contact-support` にアクセス
2. 「問合せ種別」セレクトボックスで「技術的な問題」を選択
3. 「件名」に「E2Eテスト件名」を入力
4. 「内容」に「これはE2Eテスト用のお問い合わせ内容です。」を入力
5. 「連絡先メール」に「e2e-test@example.com」を入力
6. 全項目に入力した値が表示されることを確認

**期待結果**:
- 各フィールドに正しく値が入力できる
- 入力した値がフィールドに表示される
- 送信ボタンが有効になる

---

### E2E-CONTACT-005: お問い合わせ送信完了フロー

**操作手順**:
1. `/contact-support` にアクセス
2. フォームに全項目を入力（E2E-CONTACT-004と同様）
3. 「送信する」ボタンをクリック
4. 成功メッセージ「お問い合わせを送信しました。回答まで1-2営業日お待ちください。」が表示されることを確認
5. フォームが初期状態にリセットされることを確認
6. 5秒後に成功メッセージが自動で非表示になることを確認

**期待結果**:
- 送信後、成功メッセージが表示される
- フォームの全項目がクリア（初期値に戻る）される
- 成功メッセージが5秒後に自動で消える

**注意**: このテストは実際にAPIに送信されるため、テストデータが重複しないよう、メールアドレスにタイムスタンプを付与する

---

### E2E-CONTACT-006: システム情報表示確認

**操作手順**:
1. `/contact-support` にアクセス
2. システム情報カードを確認
3. 「バージョン」行が表示されることを確認
4. 「最終更新」行が表示されることを確認
5. 「稼働状況」行が表示され、ステータスインジケーター（緑または赤の丸）が表示されることを確認

**期待結果**:
- システム情報カードに3つの情報行が表示される
- バージョン番号が表示される（例: `1.0.0`）
- 最終更新日時が表示される
- 稼働状況に「正常」または「異常」とステータスインジケーターが表示される

## 注意事項

1. **テストデータの重複回避**: お問い合わせ送信テストでは、メールアドレスにタイムスタンプを付与してユニークにする
2. **タイムアウト設定**: FAQ展開やフォーム送信は非同期処理のため、適切なwaitを設定する
3. **成功メッセージの自動非表示**: 5秒後に自動で消えるため、テスト実行順序に注意する
4. **APIとの連携**: このE2Eテストは実際のAPIを呼び出すため、バックエンドが起動している必要がある
   - バックエンド起動: `cd backend && python -m uvicorn src.main:app --host 0.0.0.0 --port 8432`
   - フロントエンド起動: `cd frontend && npm run dev`（ポート: 3247）
