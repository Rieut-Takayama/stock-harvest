## テスト詳細仕様

### E2E-ADMIN-001: ページアクセス・初期表示確認
**目的**: AdminPageが正しくレンダリングされ、モックデータが表示されることを確認

**ステップ**:
1. `/admin` にアクセス
2. ヘッダー「システム設定・管理」（SettingsIcon付き）が表示される
3. 3つのカードセクションが表示される:
   - バッチ処理ステータス
   - データソース接続状況
   - 判定条件の微調整
4. 各セクションにモックデータが表示される

**期待結果**:
- ページタイトル「システム設定・管理」表示
- 3つのカードが Grid レイアウトで表示
- モックデータがUIに反映

## 注意事項

### モック実装について
- **現在のAdminPageは完全にモック実装**:
  - バッチ処理ステータス: useState によるモックデータ
  - データソース接続状況: useState によるモックデータ
  - パラメータ設定: ローカルステートのみ（API連携なし）
  - ボタンアクション: `alert()` による仮実装

- **将来のAPI統合時の変更予定**:
  - システム情報API統合: `GET /api/system/info` からバッチステータス取得
  - LINE通知API統合: `GET /api/notifications/line/status` から接続状況取得
  - 判定パラメータAPI統合: `GET /api/config/parameters` および `PUT /api/config/parameters`

### E2Eテストの範囲
- **現時点**: モックデータの表示とUI操作のみを検証
- **API統合後**: API呼び出し → データ反映 → UI更新のフロー検証が追加される
